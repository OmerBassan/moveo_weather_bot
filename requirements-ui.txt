# The UI is a pure HTTP client of /chat. Keeping its dependencies to this short
# list is what makes that claim checkable: it cannot import the agent or the
# scoring engine, because neither is installed.

# Declared explicitly although Streamlit already pulls it in. The UI imports

# rely on staying a transitive dependency of something else -- the day

# at install time.
pandas==3.0.6
